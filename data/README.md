# Data

The project uses the public "Ecommerce Sales Data" dataset by Kanini Gichuyia.

The dataset covers transaction activity from November 2020 to October 2023 for a Kenya-based business specialising in baby products and related items.

The raw transaction-level dataset is not redistributed in this repository.

Source:
https://www.kaggle.com/datasets/kaninigichuyia/ecommerce-sales-data/versions/1
